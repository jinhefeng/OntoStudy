# 本体论学习工坊

这是依据“本体论系统学习与产品落地路线图 v0.1”制作的本地静态学习网站。

## 打开

直接用浏览器打开 dist/index.html，无需安装依赖或启动服务。

## 学习功能

- 8 个学习单元，贯穿“告警影响范围追溯”供热案例。
- 每章先用供热问题导入，再递进讲解、案例推演、辨析易混点，最后回顾本章要点并进入练习；另附延伸阅读。
- 移除各章重复的欢迎横幅和贯穿案例条；从章节标题、导读和本章问题直接进入学习。末尾预告下一章；第八章结尾引出下一轮学习。
- 每章知识段落之间有推导桥段，并以同一供热案例依序应用和收束。
- 选中正文文字可添加课程批注；标记文字带下划线，点击可查看、编辑或删除批注。批注保存在本机浏览器，可从页面右上角整体导出为 Markdown 文件。每条意见会单独标出“批注对象（精确选文）”，并附章节位置、带有选文标记的原文上下文和批注内容；文件开头也说明了如何区分选文与定位上下文，便于 AI 阅读。
- 分类题、RDF 三元组、能力问题清单、带来源与有效时间的关系图追溯、数据映射、Agent 证据输出和治理评估练习。
- 章节完成状态、练习草稿、自评和课程批注保存在当前浏览器的本地存储中。
- 页面与练习可离线使用；延伸阅读链接需要联网。

Sites 的项目 ID 保存在 .openai/hosting.json。本地文件完成不代表已同步或发布到 Sites；远端同步需要本机 Git 仓库网络连接恢复。
